    ③ 安全说明
    网页请求仅读取搜韵公开页面内容，不提交账号信息、不携带任何登录凭据；除用户手动填写代理并点击取数、或点击提交 AI 提问外，不会发起任何网络请求，也不会静默上传打卡 / 收藏 / 笔记数据。 打卡、收藏、我的笔记、DeepSeek API Key 均保存在浏览器 localStorage（仅本机可见），清除浏览器缓存会丢失记录。 笔记属于你个人的内容，只留在本机，既不上传也不随 AI 提问一起送出（提问只发送你在输入框里写的那句话）。

    AI 诗词用法简析：每张典故卡片最下方有「查看赏析」按钮（默认收起）。点击后在本机浏览器内即时生成 120 字以内的用法简析， 含表意侧重、情感倾向与两种典型手法，并引该条真实的搜韵出处与诗词用例。该分析完全由页面内置的本地分析引擎完成：不联网、不读取也不填写任何 API Key、不接入任何第三方远程大模型接口， 因此不会产生任何网络请求与费用；简析结果只缓存在当前页面内存中，刷新即重算，不写入本地存储。

    我的笔记：每张典故卡片下方都有「＋ 补充我的笔记」，点开即可用你自己的话概括这个典故（Ctrl+Enter 保存 · Esc 取消）。 写完的内容会直接显示在卡片上；顶部「我的笔记」页签可集中查看、检索、导出为 .txt，也可单条删除或一键清空。

    文献原文白话翻译：搜韵原文段落正下方有「文献原文白话翻译」按钮，点开显示逐句对照的白话译文；默认收起，不点开就不做任何计算。 译文由本机浏览器内置的本地译文引擎生成，依据为通行译注体例与《古汉语常用字字典》通行义项，词表存于同目录 local-trans.js； 全程不联网、不调用任何外部接口、不读取也不消耗任何 DeepSeek API Key 额度。未能对译的专名与僻字按原文保留，不作臆测，译文仅供理解文意参考（需要更深入的疏解，可用上方「AI 提问」，那一步需自备 Key 且由你主动联网发起）。

    数据更新：双击运行 更新搜韵数据.bat 可重新抓取搜韵人物索引与典故（默认抓典故数 ≥ 3 的人物；加 --min 1 抓全部 2513 位）； 双击 补抓典籍原文.bat 可按需补齐卡片「出处」里的典籍原文（增量补抓，已抓到的自动跳过）。
