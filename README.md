# 搜韵典故每日打卡

一个**本地端的古典诗词典故打卡网站**：整个「网站」就是一个静态 HTML 页面，存在你自己的电脑里，双击 `index.html` 即可在浏览器打开——无需安装、无需服务器、无需联网，所有数据、打卡记录、笔记都留在本机。它以「人物」为单元、按搜韵典故索引顺序轮学，每日抽取若干条典故打卡，配合收藏、笔记、日历记录，帮助日积月累地掌握古诗文中的常用典故。

典故数据来源于[搜韵](https://sou-yun.cn)典故索引的公开页面，由附带的抓取脚本一次性抓取后，以本地 JS 文件形式随页面加载，因此日常使用**完全不需要联网**；唯一的联网点是可选的「AI 提问」功能（见下文）。

## 关于搜韵（sou-yun.cn）

[搜韵](https://sou-yun.cn)（sou-yun.cn）是国内知名的**专业诗词门户网站**，长期服务于古典诗词爱好者与研究者，主要提供：

- **诗词检索**：收录历代诗词数十万首，可按诗人、朝代、体裁、词牌及句中关键字检索
- **典故索引**：按人物整理典故词条，含释义、典籍出处与诗词用例——本项目即抓取自该频道
- **韵典**：平水韵、词林正韵等韵书的在线查询
- **格律校验与填词工具**：自动检查律诗、绝句、词的平仄格律，辅助选牌填词
- **古籍影印与诗人别集**：原貌古籍与历代别集在线阅读

本项目相当于把搜韵「典故」频道的数据**搬到了离线端**：一次性抓取、本地化重组为打卡学习流程，搜韵适合检索查证，本项目适合每天按部就班地记诵。

## 功能特性

- **每日打卡**：按人物顺序轮学，可设定每次抽取的典故条数；打卡、收藏、笔记均保存在浏览器 localStorage
- **典故卡片**：典故名 / 人物 / 简释 / 出处（书名 + 卷次 + 典籍原文）/ 诗词用例
- **查看赏析**：一键生成 120 字以内的诗词用法简析（表意侧重、情感倾向、典型手法），由页面内置的**本地分析引擎**即时完成，不联网、无费用
- **文献原文白话翻译**：逐句对照白话译文，由**本地译文引擎**（`local-trans.js` 词表）完成，不联网
- **AI 提问**：围绕典故与古典诗词自由提问（释义延伸、词义辨析、赏析、横向对比），调用 DeepSeek 接口，需自备 API Key
- **收藏 / 我的笔记 / 日历记录**：集中管理，支持检索、导出 .txt
- **暗色模式**：一键切换

## 快速开始

1. 克隆或下载本仓库全部文件，**放在同一个文件夹**（数据文件用 `<script src>` 本地加载，不能拆开）
2. 双击 `index.html` 即可在浏览器中打开使用
3. （可选）右键 `index.html` → 发送到 → 桌面快捷方式，方便日常打卡

> 缺少 `souyun-people.js` / `souyun-allusions.js` 时页面会自动回退到内置的 66 条示例典故库；缺少 `local-trans.js` 时仅「白话翻译」按钮不显示，其余功能不受影响。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页面（含全部样式与逻辑、内置本地赏析 / 译文引擎、兜底示例库） |
| `souyun-people.js` | 人物列表（按搜韵页面顺序，含每人典故总数） |
| `souyun-allusions.js` | 典故明细（典故名 / 释义 / 出处 / 典籍原文 / 诗词例句） |
| `local-trans.js` | 本地白话译文词表 |
| `更新搜韵数据.py` / `.bat` | 从搜韵公开页面抓取 / 更新数据（自适应限流、断点续抓） |
| `补抓典籍原文.bat` | 增量补齐卡片「出处」中的典籍原文 |
| `重新生成桌面快捷方式.ps1` | 一键生成桌面快捷方式 |

## AI 与模型说明

本项目的 AI 能力分为三层，**各层是否用模型、用哪个模型完全不同**：

| 能力 | 谁来生成提示词（Prompt） | 谁来执行（操作） | 是否联网 |
| --- | --- | --- | --- |
| AI 提问（DeepSeek 辅助） | **无模型生成**——System Prompt 是开发期人工写死的固定文本（`index.html` 中的 `SYS` 常量），运行时原样发送，用户问题作为 User 消息拼接 | **DeepSeek `deepseek-chat`**（[api.deepseek.com](https://api.deepseek.com/chat/completions)） | 是，仅在你点击「提交问题」时 |
| 查看赏析（用法简析） | 不涉及外部提示词 | **页面内置的本地规则分析引擎**（浏览器内即时计算） | 否 |
| 文献原文白话翻译 | 不涉及外部提示词 | **本地译文引擎**（`local-trans.js` 词表 + 通行译注体例规则） | 否 |

即：**整个项目运行时唯一用到的模型是 DeepSeek `deepseek-chat`，且只服务于「AI 提问」功能**；提示词本身不由任何模型生成，而是固定写在代码里并做了严格约束（只答典故与古典诗词话题、严禁编造诗句、简体中文简明作答）。

使用「AI 提问」需要：

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com) 申请 API Key
2. 在页面「AI 提问」区域填入并点「保存」（Key 仅存本机浏览器 localStorage，不上传到任何服务器）
3. 输入问题，点「提交问题」——只有这一步会联网，且只发送你输入框里的那句话

## 数据更新

双击 `更新搜韵数据.bat` 重新抓取搜韵人物索引与典故（默认抓典故数 ≥ 3 的人物；`python 更新搜韵数据.py --min 1` 可抓全部 2513 位）。抓取脚本仅读取搜韵公开页面，不提交任何账号信息，内置自适应限流与断点续抓。

## 声明

- 典故数据抓取自搜韵（sou-yun.cn）公开页面，仅用于个人学习，请勿用于商业用途
- 打卡、收藏、笔记、API Key 全部保存在本机浏览器 localStorage，本项目不设任何服务器、不上传任何用户数据
- 译文与赏析由本地规则引擎生成，仅供理解文意参考
